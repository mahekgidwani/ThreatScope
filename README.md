# ThreatScope

Unified cyber threat detection and monitoring platform (college project). It collects
security events from domain-squatting detection, a web honeypot, file analysis and
network monitoring into one PostgreSQL database behind a FastAPI backend.

Status: Phase 2 (backend foundation) in progress. Full setup and usage instructions
will be added at the end of Phase 2.

See `docs/` for the Phase 1 audit, the design specification, the implementation plan
and the development log.
